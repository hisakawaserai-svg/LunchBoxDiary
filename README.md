# LunchBoxDiary

作ったお弁当を、写真で記録して、カレンダーで振り返る日記アプリ(iOS)。

家族が使っていた料理保存アプリがサービスを終了し、お弁当を残す場所がなくなったことから、家族の要望をもとに作っている。

## 現在の状態

試作で確かめたうえで、実装を始める段階。すべての機能が動くわけではない。

| 機能 | 状態 |
|---|---|
| 月のカレンダー(月の切り替え、記録のある日に写真を表示) | 試作で動作を確認済み |
| 写真の縮小・圧縮・保存 | 検証済み(1日1件で、1年あたり約83.5MB) |
| フレーム | 「ほしの枠」の大きいカードだけ試作 |
| 追加画面 | 試作(タイトル、写真、日付) |
| 詳細シート、写真の全体表示 | 未着手 |
| リスト表示、絞り込み | 未着手(方針は設計書にある) |
| 「誰に」「イベント名」の登録・編集 | 未着手 |

## 技術

- Swift / SwiftUI / SwiftData
- 対象 OS: iOS 17 以上

- 作り方に迷う部分(写真の保存容量、カレンダーの月の持ち方、フレームの表現など)は、先に小さい試作で確かめ、結果を `docs/verification.md` に記録した。
